# Петрович

Ворчливый инженер в Telegram. Не ассистент и не помощник — просто мужик в чате, который говорит что думает, любит выпить и травит анекдоты.

Поднимается в Docker **одной командой**. Никаких сервисов в системе, никаких pip-зависимостей, никакой базы данных.

```
git clone <этот репозиторий> petrovich && cd petrovich
cp .env.example .env          # вписать TG_TOKEN
./scripts/download-models.sh  # скачать модель (2.4 ГБ)
docker compose up -d --build
```

Всё. Напишите боту в личку — он ответит.

---

## Что внутри

| Контейнер | Что делает |
|---|---|
| `llama` | llama.cpp с локальной моделью — мозг для `BRAIN=local` и запасной вариант, если облако недоступно |
| `classifier` | отдельный llama.cpp для распознавания рекламы от других ботов |
| `bot` | сам Петрович: Python 3.12, только стандартная библиотека |

Мозг может быть облачным или локальным — переключается одной переменной:

```env
BRAIN=zai     # облако Z.ai, быстро и дёшево (нужен ZAI_API_KEY)
BRAIN=local   # локально в контейнере llama, медленнее, но без облака
```

Если облако отваливается, бот **сам** уходит на локальную модель — не молчит.

## Настройка

Всё в `.env`. Обязательна одна переменная — `TG_TOKEN` (токен от [@BotFather](https://t.me/BotFather)).

Остальное — по вкусу: имя бота, слова-триггеры, фраза для ответа на рекламу, часовой пояс, размер контекста. Полный список с пояснениями — в `.env.example`.

**Люди из чата.** Если персонаж должен знать кого-то по имени — перечислите их в `KNOWN_PEOPLE` (через запятую). В репозитории этот список намеренно пуст: чужие ники сюда не попадают.

**Персонаж правится в `bot/persona.txt`** — это обычный текст, системный промпт. Перезапуск не нужен: файл читается на каждом сообщении.

## Как он себя ведёт

- **В личке молчит.** Так задумано: иначе его задёргают в личных сообщениях.
- **В группе отвечает, когда позвали** — по `@упоминанию` или по словам из `KEYWORDS` («петрович», «алкаш»). Остальное читает, но не влезает.
- **На рекламу от других ботов огрызается** фразой из `SPAM_REPLY`. Спам определяется локально: сначала по ключевым словам, если не сработало — крошечной моделью. Облако для этого не используется.
- **Ищет в интернете**, когда нужен свежий факт (погода, новости, курсы).
- **Знает текущую дату** — она подставляется в промпт на каждом запросе.

## Что нужно сделать в @BotFather

1. `/newbot` — создать бота, получить токен.
2. `/setprivacy` → выбрать бота → **Disable**. Без этого в группах он видит только команды, а не разговор.
3. Если бота добавили в группу **до** отключения privacy — удалить и добавить заново, иначе Telegram не начнёт отдавать ему сообщения.

## Требования

- Docker с плагином compose
- ~3 ГБ диска на модель, ~4 ГБ оперативной памяти
- Работает на x86-64 и ARM64 (проверено на ARM Ampere)

Слабое железо? Поставьте `BRAIN=zai` и маленькую модель для классификатора — тогда локальная модель почти не используется, и хватает 1 ГБ памяти.

## Про секреты

В репозитории **нет и не должно быть** токенов и ключей. Всё, что секретное, живёт в `.env`, а он в `.gitignore`.

Если случайно закоммитили токен — считайте его скомпрометированным и перевыпустите через @BotFather. Удаление коммита не помогает: он остаётся в истории.
